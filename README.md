# Invoice Assignment

The invoice assignment is the assignment for lesson 9 at IT-Högskolan.

The assignment was given to us by [Michael Gustavsson](https://github.com/Michael-Gustavsson).

## The Assignment

Originally, the assignment was to figure out what represents an invoice and create a simple application that lets the user interact with it.

## My Solution

I made a simple console application that simulates a webshop. The user can browse a product catalog, add products to their basket and remove products from it.

The user can then access an invoice manager where they can view their invoice and pay it.

## How to Run

### Requirements

You need to have the **.NET SDK** installed on your computer.

You can check if .NET is installed by opening a terminal and running:

```bash
dotnet --version
```

If a version number is displayed, .NET is installed.

### Running the Application
Download or clone this repository.
Open a terminal in the project folder, where the .csproj file is located.
Run the application:
```bash
dotnet run
```
The application should now start in the terminal.

### Using the Application

Once the application starts, follow the instructions displayed in the console.

You can browse the product catalog, add and remove products from your basket, and access the invoice manager to view and pay your invoice.
